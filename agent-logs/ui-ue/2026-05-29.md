# UI/UE Agent Log - 2026-05-29

## Task

Prepare Western-market UI directions for a future English/global version.

## Initial Scope

- Keep current core function unchanged.
- Improve readability for European and American users.
- Preserve an Eastern mystical feeling without making the page look inaccessible.

## Status

Investigation delegated to UI/UE sub-agent. Results should be merged here before implementation.

## Western-Market UI Concepts

### 1. Mystic Analyst

- Visual keywords: midnight ink, parchment contrast, vermillion seal, constellation grid, quiet premium.
- Layout: keep the seal/star-chart mood, but use a Western insight-dashboard flow. Form becomes a 3-step wizard: birth date, birth time/location, reading preferences. Results start with `Your Core Pattern` and a summary before the technical Four Pillars chart.
- Content: explain each first-use term with `What this means` and `Traditional basis`. Keep Chinese/Japanese characters as credibility/visual anchors, not as required reading.
- Risk: could become too much like a generic personality tool if the traditional basis is hidden too far.
- Recommendation: best MVP direction for English/global users.

### 2. Eastern Codex

- Visual keywords: ancient manuscript, celestial archive, oracle document, red stamp, annotated chart.
- Layout: a modern interactive manuscript. Reading order: overview, chart, elements, love/career, timing. The Four Pillars table remains visually central but has clear English labels: Year Pillar, Month Pillar, Day Pillar, Hour Pillar.
- Content: pair characters with English, such as `甲 Yang Wood`; keep advanced fields collapsible; use `Traditional reading` plus `Plain English`.
- Risk: strong brand feeling but may feel niche or dense, especially on mobile.

### 3. Celestial Wellness

- Visual keywords: soft night sky, elemental balance, personal reflection, calm spiritual app.
- Layout: closer to familiar Western astrology/wellness flows. First result screen shows Element Balance and Core Self. Four Pillars chart moves to an `Advanced Chart` tab.
- Content: emphasize accessible Five Element meanings, tooltips, glossary, and shareable summaries while avoiding deterministic claims.
- Risk: easiest to understand, but may dilute the Shichusuimei/Bazi differentiation.

## Recommendation

Use `Mystic Analyst` for the first Western MVP. Keep `Eastern Codex` as a brand-rich variant for advanced users or an editorial/landing direction. Treat `Celestial Wellness` as a later simplified mobile entry if needed.
